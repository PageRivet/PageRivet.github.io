About PageRivet

AI와 웹 코드를 더 자연스럽게 연결하는 작업 공간

PageRivet은 HTML, CSS, JavaScript로 구성된 정적 웹 프로젝트를 만들고 편집하며, 결과를 바로 확인할 수 있는 Windows 데스크톱 에디터입니다.

Why PageRivet

필요에서 시작된 도구

PageRivet은 처음부터 범용 웹 에디터를 목표로 시작한 프로그램이 아닙니다. AI로 HTML, CSS, JavaScript 코드를 만들 때마다 생성된 내용을 확인하고, 필요한 부분을 수정한 뒤 다시 적용하는 과정이 반복됐습니다.

이 불편한 흐름을 한곳에서 다룰 수 있는 도구가 필요했습니다. 단순한 코드 편집과 미리보기 기능으로 시작했지만, 실제 작업에서 필요한 기능을 하나씩 더하며 지금의 PageRivet으로 발전했습니다.

Core Workflow

웹 프로젝트의 흐름을 한곳에서

코드를 작성하는 순간부터 결과를 확인하고, 문제를 찾고, 이전 상태로 돌아가는 과정까지 하나의 작업 공간으로 연결합니다.

01

편집과 미리보기

여러 HTML, CSS, JavaScript 파일을 관리하고 WebView2 기반 미리보기로 변경 결과를 즉시 확인합니다.

02

검증과 진단

코드 검증과 오류·콘솔 정보를 통해 문제가 발생한 지점을 더 빠르게 확인할 수 있습니다.

03

기록과 복구

History, Undo/Redo, 과거 상태 복원과 외부 파일 변경 감지를 통해 작업 흐름을 안전하게 관리합니다.

MCP & AI Collaboration

특정 AI가 아닌,
사용자가 선택하는 AI

PageRivet은 API 토큰을 등록해 특정 AI 서비스를 프로그램 안에 직접 내장하는 대신 MCP를 선택했습니다. 하나의 서비스에 종속되기보다 사용자가 원하는 AI 클라이언트를 선택할 수 있는 구조가 더 적합하다고 판단했기 때문입니다.

로컬 MCP 서버를 통해 Codex, Claude Code, Cursor, VS Code 및 GitHub Copilot 같은 MCP 클라이언트가 프로젝트를 읽고 분석할 수 있습니다. 코드 변경은 검증과 사용자 승인 과정을 거쳐 안전하게 적용됩니다.

How It Was Built

AI와 함께, 반복해서 완성했습니다

PageRivet의 기획과 필요한 기능, 동작 방식, 주요 설계 방향은 실제 사용 흐름을 기준으로 정했습니다. 구현에는 AI를 적극적으로 활용했지만, 한 번의 프롬프트로 생성한 결과물이 아닙니다. 결과를 직접 확인하고 문제를 다시 정의하며 구조와 기능을 반복해서 다듬었습니다.

Focused Scope

PageRivet이 집중하는 것

PageRivet은 웹 빌더나 전문 IDE를 대체하려는 프로그램이 아닙니다. 서버, CMS, 호스팅 기능을 포함하지 않으며 정적 HTML, CSS, JavaScript 프로젝트와 안전한 AI 협업에 집중합니다.
