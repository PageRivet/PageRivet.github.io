PageRivet 2.2.1 Update

2026.08.25Windows x64Portable
Latest Release

리소스 관리, 다중 인스턴스 복구와 MCP 연결, 39개 MCP 명령어, 새로운 워크벤치 디자인을 하나의 공개 버전으로 제공합니다.

39MCP 명령어
8리소스 분류
Multi인스턴스 연결
추가새롭게 사용할 수 있는 기능+
  • 프로그램 시작 화면을 PageRivet 공식 홈페이지와 연결했습니다.
  • 공식 홈페이지를 불러오지 못할 때 내장 오프라인 안내 화면을 표시합니다.
  • 추가 HTML·CSS·JavaScript 파일을 안전한 프로젝트 하위 디렉터리에서 관리할 수 있습니다.
  • 프로젝트 리소스 탭에서 이미지, 폰트, 동영상, 오디오, 문서, 데이터, 웹 자산과 3D 모델을 가져오고 이름을 변경하거나 삭제할 수 있습니다.
  • 리소스를 assets/images, assets/fonts, assets/videos, assets/audio, assets/documents, assets/data, assets/web, assets/models로 자동 분류합니다.
  • 프로젝트 저장, 다른 이름으로 저장, 미리보기, Web Folder와 ZIP 내보내기에 하위 소스와 관리 리소스를 포함합니다.
  • MCP 리소스 조회 명령어 get_project_resources를 추가했습니다.
  • MCP 리소스 쓰기 명령어 import_project_resource, rename_project_resource, delete_project_resource를 추가했습니다.
  • 내장 MCP 명령어를 총 39개로 확장했습니다.
  • PageRivet을 여러 개 실행할 때 각 인스턴스가 순차 MCP 포트와 고유 연결 이름을 사용합니다.
  • Codex, Claude Code와 JSON 설정 기반 MCP 클라이언트에서 여러 PageRivet 인스턴스 연결을 함께 등록할 수 있습니다.
  • 프로세스별 복구 세션 저장소를 추가했습니다.
변경기존 흐름과 사용성 개선+
  • 프로젝트 파일 경로를 루트 파일명 대신 안전한 프로젝트 상대 경로로 처리하도록 확장했습니다.
  • 필수 index.html, style.css, script.js는 호환성을 위해 프로젝트 루트에 유지합니다.
  • 리소스 가져오기는 원본 외부 경로와 대상 경로를 표시하고 항상 명시적 사용자 승인을 받습니다.
  • MCP 연결 창에 현재 전송 방식과 인스턴스별 연결 이름을 표시합니다.
  • 한국어·영어 UI와 내장 가이드를 리소스 관리 및 39개 MCP 명령어 기준으로 갱신했습니다.
  • 메인 화면과 대화상자를 어두운 워크벤치 디자인으로 개편하고 미리보기, 코드, 진단 영역을 명확한 색상 톤으로 구분했습니다.
  • 코드 편집기의 글꼴, 배경, 줄 번호와 HTML·CSS·JavaScript 구문 색상을 어두운 작업 환경에 맞게 조정했습니다.
  • 리소스 관리 버튼을 동일한 크기의 2×2 배열로 정리하고 빈 리소스 안내와 미리보기 영역의 가독성을 개선했습니다.
  • 제품, 어셈블리와 파일 버전을 2.2.1로 통일했습니다.
수정안정성과 화면 표시 문제 해결+
  • PageRivet을 두 개 이상 실행할 때 두 번째 프로세스에서 복구 기능을 시작하지 못하던 문제를 수정했습니다.
  • MCP 기본 포트가 이미 사용 중이면 두 번째 프로세스부터 MCP 서버를 시작하지 못하던 문제를 수정했습니다.
  • 하위 디렉터리 소스의 미리보기 URL, 링크 해석, 외부 변경 감지와 내보내기 누락 문제를 방지했습니다.
  • MCP 리소스 작업 후 에디터의 리소스 목록과 미리보기가 즉시 갱신되도록 했습니다.
  • 코드 및 진단 탭을 더블 버퍼링 방식으로 그려 탭 전환과 코드 입력 중 발생하던 흰색 깜빡임을 줄였습니다.
  • 기록과 MCP 로그의 열 뒤에 남던 흰색 네이티브 헤더 영역을 제거했습니다.
  • WinForms 테두리와 불완전한 라운드 클리핑을 제거하고 색상 톤만으로 작업 영역을 구분하도록 수정했습니다.
보안프로젝트와 사용자 정보 보호+
  • 프로젝트 상대 경로가 프로젝트 루트 밖으로 벗어나지 못하도록 경로 정규화와 Windows 예약 이름 검사를 적용했습니다.
  • 관리 리소스 디렉터리의 심볼릭 링크와 재분석 지점 사용을 차단했습니다.
  • MCP 리소스 요청 적용 전에 프로젝트 Revision, 현재 리소스 목록과 가져오기 원본 상태를 다시 확인합니다.
  • 외부 리소스 원본 경로와 MCP 인증 정보를 도구 응답 및 포터블 배포본에 포함하지 않습니다.
