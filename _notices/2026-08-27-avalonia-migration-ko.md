PageRivet의 Avalonia 이식 작업이 현재 마무리 단계에 들어갔습니다.

주요 기능의 이식은 상당 부분 완료되었으며, 현재는 전체적인 구조를 다시 점검하고 중복되거나 불필요하게 결합된 부분을 정리하면서 기존 기능이 새로운 구조에서도 안정적으로 동작하도록 개선하는 작업을 진행하고 있습니다.

## Windows 지원

현재 개발 및 테스트는 Windows 환경을 기준으로 진행하고 있습니다.

Windows 환경에서는 주요 기능의 이식이 상당 부분 완료되었으며, 현재 상태라면 Avalonia 기반 PageRivet의 Windows 이식 완료를 기대해도 괜찮을 것으로 보고 있습니다.

다만 아직 최종 검증과 구조 정리 작업이 남아 있으며, 개발 과정에서 예상하지 못한 문제나 추가 수정이 필요한 부분이 발견될 경우 이식 완료 시점은 현재 예상보다 늦어질 수 있습니다.

정확한 완료 날짜를 미리 확정하기보다는, 기존 PageRivet의 주요 기능과 안정성이 충분히 유지되는 것을 확인한 뒤 다음 단계로 진행할 예정입니다.

## macOS 및 Linux 지원

아쉬운 점은 현재 macOS와 Linux에 대한 실제 테스트 환경이 마련되어 있지 않다는 것입니다.

Avalonia로 이식하면서 기존 Windows 전용 구조에서 벗어나 다른 운영체제로 확장할 수 있는 기반과 통로는 열어두고 있습니다. 따라서 macOS와 Linux 지원을 기술적으로 배제한 것은 아닙니다.

다만 실제 환경에서 충분한 테스트를 진행하지 않은 상태에서 공식적인 지원을 약속하는 것은 적절하지 않다고 판단하고 있습니다.

현재로서는 Windows 지원을 우선하며, macOS와 Linux는 향후 테스트 환경이 마련되고 실제 검증이 가능해질 경우 지원 범위를 확장하는 방향으로 검토할 예정입니다.

언제 해당 환경을 마련할 수 있을지는 현재로서는 장담하기 어렵습니다. 하지만 여건이 갖춰진다면 macOS와 Linux에서도 PageRivet을 사용할 수 있도록 가능한 범위에서 최선을 다해 지원을 확대하겠습니다.

## 향후 진행

당분간은 다음 작업에 집중할 예정입니다.

- Avalonia 이식 구조 최종 정리
- 기존 PageRivet 주요 기능 재검증
- Windows 환경 안정성 확인
- 기존 기능과 새로운 구조 간 회귀 문제 점검
- 배포 가능한 상태까지 최종 정리

이식 진행 상황에 의미 있는 변화가 있을 경우 공식 홈페이지와 관련 플랫폼을 통해 다시 안내드리겠습니다.
