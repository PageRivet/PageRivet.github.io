PageRivet은 현재 사용자의 작업 편의성을 높이기 위해 기존의 고정형 UI 구조를 개선하고 있습니다.

앞으로는 정해진 화면 구성만 사용하는 방식에서 벗어나, **사용자가 자신의 작업 방식에 맞게 레이아웃을 직접 구성하고 조정할 수 있는 환경**을 제공하는 것을 목표로 개발을 진행하고 있습니다.

## 사용자 중심의 레이아웃 개선

PageRivet을 사용하는 사용자마다 자주 확인하는 영역과 작업 순서가 다를 수 있다는 점을 반영해, 기존의 고정된 패널 구성보다 더욱 유연한 작업 환경을 제공하려고 합니다.

이번 개선은 단순한 외형 변경보다는 사용자가 필요한 영역을 자신의 작업 흐름에 맞게 구성할 수 있도록 하는 데 목적이 있습니다.

레이아웃 관련 기능은 기존 PageRivet의 주요 기능과 안정성을 유지하는 범위에서 단계적으로 적용하고 검증할 예정입니다.

## 업데이트 일정 변경

최초 공개 이후 PageRivet은 기능 추가와 개선, 안정화 작업이 빠르게 진행되면서 비교적 짧은 간격으로 여러 버전이 배포되었습니다.

빠르게 문제를 수정하고 기능을 개선할 수 있다는 장점이 있었지만, 사용자 입장에서는 새로운 버전을 자주 확인하고 교체해야 하는 불편이 있을 수 있다고 판단했습니다.

이에 따라 **`3.3.0-beta.2` 버전부터 긴급한 패치를 제외한 일반 업데이트는 원칙적으로 매주 수요일 또는 목요일에 진행할 예정입니다.**

가능한 한 한 주 동안 확인된 개선 사항과 수정 내용을 정리해 함께 제공하고, 불필요하게 짧은 간격으로 버전이 교체되는 상황을 줄이는 방향으로 운영하겠습니다.

## 긴급 패치

다음과 같이 즉각적인 대응이 필요한 문제가 확인되는 경우에는 정기 업데이트 일정과 관계없이 별도의 긴급 패치가 배포될 수 있습니다.

- 프로그램 사용에 큰 영향을 주는 오류
- 프로젝트 또는 사용자 데이터 손상 가능성이 있는 문제
- 보안과 관련된 문제
- 정상적인 주요 기능 사용을 어렵게 만드는 중대한 문제

긴급성이 낮은 기능 개선과 일반적인 버그 수정은 가능한 한 정기 업데이트 일정에 맞춰 반영할 예정입니다.

## 사용자 피드백

PageRivet은 실제 사용 과정에서 확인되는 의견과 문제를 바탕으로 계속 개선하고 있습니다.

사용 중 불편한 점이나 개선이 필요한 부분, 추가되었으면 하는 기능 등이 있다면 언제든지 의견을 남겨주시기 바랍니다.

앞으로도 보다 안정적이고 편리한 작업 환경을 제공할 수 있도록 지속적으로 개선하겠습니다.

많은 관심과 적극적인 피드백 부탁드립니다.
