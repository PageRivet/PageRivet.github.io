PageRivet is currently being improved to provide a more flexible and convenient working environment.

Instead of relying only on a fixed interface layout, we are working toward allowing **users to arrange and adjust the workspace layout to better match their own workflow**.

## A More Flexible Workspace

Different users may focus on different panels and follow different workflows while working in PageRivet.

To better support these differences, we are improving the current fixed layout so that users can organize the workspace more flexibly according to their needs.

This work is intended to improve usability rather than simply change the appearance of the application.

Layout-related features will be introduced and verified gradually while preserving the stability and major functionality of PageRivet.

## Update Schedule Changes

Since the initial public release, PageRivet has received frequent updates as new features, improvements, and stabilization work have progressed rapidly.

While this has made it possible to address issues and improve the application quickly, we recognize that frequent version changes can also make it inconvenient for users to repeatedly check for and replace releases.

For this reason, **starting with version `3.3.0-beta.2`, regular updates will generally be released on Wednesday or Thursday each week, except when an urgent patch is required.**

Whenever possible, improvements and fixes identified during the week will be grouped into a scheduled release instead of being distributed through unnecessarily frequent version changes.

## Urgent Patches

An update may still be released outside the regular schedule if an issue requires immediate attention, including:

- Errors that significantly affect normal use of the application
- Issues that may risk project or user data
- Security-related problems
- Serious defects that prevent major features from functioning normally

Non-urgent improvements and general bug fixes will, whenever possible, be included in the regular update schedule.

## User Feedback

PageRivet continues to improve based on issues and feedback discovered through real-world use.

If you encounter any inconvenience, find something that could be improved, or have a suggestion for a useful feature, please feel free to share your feedback.

We will continue working to make PageRivet more stable, flexible, and convenient to use.

Thank you for your continued interest and feedback.
