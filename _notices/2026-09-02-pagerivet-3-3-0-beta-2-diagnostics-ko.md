PageRivet `3.3.0-beta.2` 업데이트와 함께, 사용 중 발생하는 문제를 보다 정확하게 확인하기 위한 **PageRivet 전용 진단기(PageRivet Diagnostics)**를 추가했습니다.

## PageRivet 3.3.0-beta.2 업데이트

이번 버전에서는 사용자가 직접 작업공간을 구성할 수 있는 도킹 시스템과 레이아웃 저장·복원, 사용자 지정 테마, 프로젝트 소스 트리 및 검색, History 복원, 통합 설정창 등이 추가되었습니다.

또한 `_config.yml` 기반의 Jekyll 사이트 미리보기를 지원하며, 오류/디버그 표시와 패널·탭·독립 창 등 전반적인 작업 환경도 개선했습니다.

기존 HTML 및 PageRivet YAML 미리보기, 프로젝트 편집·저장, History, Recovery, 리소스, 내보내기와 MCP 기능은 그대로 유지됩니다.

## PageRivet 전용 진단기 추가

PageRivet을 사용하면서 발생하는 문제를 확인하기 위한 별도의 **PageRivet Diagnostics**를 함께 제공합니다.

진단기는 PageRivet의 설치 및 실행 환경을 비롯해 WebView2, MCP 연결, 관련 런타임과 프로그램 상태 등 문제의 원인을 파악하는 데 필요한 여러 항목을 확인하고 진단 결과를 보고서로 생성합니다.

PageRivet 사용 중 문제가 발생하여 문의 또는 버그 제보를 남기실 경우, 가능하다면 **진단기를 실행한 뒤 생성된 진단 결과를 함께 첨부해 주세요.**

단순한 증상 설명만으로 원인을 확인하기 어려운 경우에도 진단 결과를 함께 제공해 주시면 실행 환경과 관련 상태를 확인할 수 있어 문제를 보다 정확하게 파악하는 데 도움이 됩니다.

## 시스템 정보 포함 옵션 안내

진단기의 **`시스템 정보 포함`은 선택 사항**입니다.

해당 옵션을 활성화하면 문제 분석을 위해 다음과 같은 시스템 구성 및 실행 환경 정보가 진단 결과에 포함될 수 있습니다.

- Windows 제품·버전·빌드 및 시스템 아키텍처
- 시스템 제조사 및 제품명, BIOS 버전
- CPU 및 GPU, 그래픽 드라이버 정보
- 물리 메모리 용량 및 사용 상태
- PageRivet 관련 저장장치의 유형·파일시스템·용량
- .NET, WebView2, Jekyll 관련 런타임 정보
- 시스템 가동 시간, 시간대 및 표시 문화권

반면 진단기는 **사용자명, 컴퓨터명, IP 주소, MAC 주소, Wi-Fi SSID, 프록시 주소, 경로 원문, 장치·디스크·모니터 시리얼 번호 및 Windows 제품 키를 수집하지 않도록 구성되어 있습니다.**

시스템 구성 정보 제공을 원하지 않는 경우 `시스템 정보 포함`을 선택하지 않고 진단을 진행할 수 있습니다.

## 문제 문의 시

PageRivet 사용 중 오류나 예상하지 못한 동작이 발생한다면 다음 내용을 함께 전달해 주시면 문제 확인에 도움이 됩니다.

- 발생한 문제와 당시 수행했던 작업
- 가능하다면 문제가 발생한 화면 또는 오류 메시지
- PageRivet Diagnostics에서 생성한 진단 결과

실제 사용 환경에서 확인되는 문제와 피드백을 바탕으로 PageRivet을 지속적으로 개선하겠습니다.

감사합니다.
