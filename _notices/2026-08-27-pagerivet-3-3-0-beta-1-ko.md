PageRivet의 Avalonia 이식 및 기존 UI 구조 교체 작업이 완료되었습니다.

이제 `3.3.0-beta.1` 버전부터 Avalonia 기반으로 전환된 새로운 PageRivet을 사용할 수 있습니다.

## Avalonia 전환 완료

기존 Windows 전용 UI 구조를 Avalonia 기반으로 교체하는 작업을 마쳤으며, 현재 제작 및 개발 환경에서는 주요 기능이 정상적으로 동작하는 것을 확인했습니다.

기존 PageRivet의 주요 기능을 유지하면서 새로운 구조에서도 프로젝트 편집, 미리보기, MCP 연동 및 관련 기능들이 정상적으로 동작하도록 검증을 진행했습니다.

## Beta 버전으로 제공하는 이유

현재 제작 환경에서는 정상적인 동작을 확인했지만, 실제 사용자 환경은 운영체제 버전, 하드웨어 구성, WebView 환경, 파일 권한, 보안 프로그램 및 기타 시스템 설정 등에 따라 차이가 있을 수 있습니다.

따라서 실제 사용 과정에서 예상하지 못한 크고 작은 문제가 발생할 가능성이 있습니다.

이러한 이유로 Avalonia 전환 이후 첫 공개 버전에는 `beta` 태그를 적용했으며, `3.3.0-beta.1`부터 실제 사용자 환경에서 발생하는 문제와 피드백을 확인하며 안정성을 보완할 예정입니다.

`beta` 표시는 PageRivet을 사용할 수 없는 상태라는 의미가 아니라, **새로운 Avalonia 구조가 다양한 실제 환경에서도 안정적으로 동작하는지 추가 검증이 필요한 단계**라는 의미입니다.

## macOS 및 Linux 지원

앞서 안내드린 것과 마찬가지로 현재 macOS와 Linux에 대한 실제 개발 및 테스트 환경은 마련되어 있지 않습니다.

Avalonia 전환을 통해 두 운영체제로 확장할 수 있는 구조와 가능성은 열어두었지만, 실제 환경에서 충분한 테스트를 수행할 수 없는 상태이므로 현재 시점에서 macOS 및 Linux의 공식 지원을 약속드리기는 어렵습니다.

현재 `3.3.0-beta.1`은 Windows 환경을 기준으로 개발 및 검증하고 있습니다.

향후 macOS 또는 Linux 테스트 환경이 마련되고 충분한 검증이 가능해진다면 해당 운영체제에서도 PageRivet을 사용할 수 있도록 지원 범위를 확대하는 방향으로 검토하겠습니다.

## 향후 진행

당분간은 다음 작업에 집중할 예정입니다.

- `3.3.0-beta.1` 실제 사용자 환경 테스트
- Avalonia 전환 이후 발생하는 회귀 문제 확인
- UI 및 기능 안정성 보완
- MCP 및 프로젝트 작업 흐름 재검증
- 사용자 피드백을 기반으로 한 문제 수정
- 안정화 이후 정식 버전 전환 검토

실제 사용 중 문제가 발견되거나 중요한 변경 사항이 있을 경우 공식 홈페이지와 관련 플랫폼을 통해 계속 안내드리겠습니다.
