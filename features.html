Features

PageRivet으로 할 수 있는 일

정적 웹 프로젝트를 만들고 편집하는 순간부터 미리보기, 검증, 기록과 복구, 내보내기까지 하나의 작업 환경에서 관리합니다.

Project & Editing

프로젝트와 코드를 한곳에서 관리합니다

하나의 파일만 편집하는 도구가 아니라 여러 HTML, CSS, JavaScript 파일로 구성된 정적 웹 프로젝트 전체를 다룹니다.

▣

프로젝트 생성과 관리

새 프로젝트를 시작하거나 기존 프로젝트를 열고 파일 단위 작업부터 전체 프로젝트 저장까지 이어서 처리합니다.

  • 새 프로젝트 생성 및 기존 프로젝트 열기
  • 저장 및 다른 이름으로 저장
  • 다중 HTML, CSS, JavaScript 파일 관리
  • 파일 생성, 이름 변경, 삭제
</>

HTML, CSS, JavaScript 편집

코드를 직접 편집하고 현재 작성 중인 내용과 프로젝트에 적용된 정상 상태를 구분해 관리합니다.

  • 구문 강조와 줄 번호
  • 검색과 줄 이동
  • 저장되지 않은 변경 표시
  • 적용 전 검증을 거치는 안전한 반영
Preview, Validate, Recover

결과를 확인하고 안전하게 되돌립니다

01

웹 페이지 미리보기

WebView2 기반 미리보기에서 HTML 페이지를 선택하고 CSS와 JavaScript 적용 결과를 바로 확인합니다.

  • 코드 적용 후 자동 갱신
  • 미리보기 페이지 선택
  • 미리보기 최대화 및 복원
02

코드 검증과 오류 확인

프로젝트에 변경을 적용하기 전에 HTML, CSS, JavaScript의 문제를 확인합니다.

  • 파일·줄·열 기준 오류 표시
  • 실행 예외 및 콘솔 메시지 확인
  • 여러 파일을 하나의 변경 단위로 처리
03

히스토리와 복구

변경 기록을 확인하고 원하는 시점을 선택해 복원합니다. 복원 역시 새로운 기록으로 남습니다.

  • Undo 및 Redo
  • 변경 히스토리 조회
  • 과거 상태 선택 및 복원
  • 최대 Undo 횟수 설정
External Changes

외부 변경도 같은 흐름으로

다른 편집기나 도구에서 파일이 변경되면 이를 감지하고 다시 검증합니다. 정상적인 변경만 프로젝트 상태에 반영하고 히스토리에 기록합니다.

Export

일반적인 웹 프로젝트로 내보내기

작업 결과는 PageRivet에 종속되지 않습니다. 프로젝트 폴더, ZIP 또는 코드 복사 방식으로 내보내 계속 사용할 수 있습니다.
