MCP & AI Collaboration

사용자가 선택한 AI와 함께 작업합니다

PageRivet은 특정 AI를 직접 내장하지 않습니다. 로컬 MCP 서버를 통해 사용자가 선택한 AI 클라이언트와 프로젝트를 연결합니다.

Why MCP

PageRivet이 정하는 AI가 아닌,
사용자가 선택한 AI와 연결합니다

특정 모델이나 채팅 기능에 종속되는 대신 MCP를 사용합니다. 사용자는 익숙한 AI 클라이언트에서 자연어로 요청하고, AI는 PageRivet의 활성 프로젝트를 기준으로 코드를 확인하고 작업합니다.

Connected Workflow

복사와 붙여넣기를 하나의 흐름으로

AI와 편집기 사이에서 코드를 반복해서 옮기는 과정을 줄이고 사용자와 AI가 같은 프로젝트를 기준으로 협업합니다.

일반적인 작업 흐름
  1. AI에게 코드 요청
  2. 생성된 코드 확인
  3. 코드 복사 및 붙여넣기
  4. 결과 확인
  5. 다시 수정 요청
PageRivet + MCP
  1. 사용자가 AI에게 작업 요청
  2. AI가 PageRivet 프로젝트 확인
  3. 필요한 코드 분석 및 변경
  4. PageRivet에서 검증과 적용
  5. 사용자가 결과 확인
AI Capabilities

연결된 AI가 할 수 있는 일

프로젝트 이해

  • 활성 프로젝트 정보와 상태 확인
  • 프로젝트 파일 목록 조회
  • HTML, CSS, JavaScript 읽기

코드 작업

  • HTML, CSS, JavaScript 수정
  • 파일 생성 및 이름 변경
  • 필요한 파일 삭제

오류 확인

  • 프로젝트 검증 요청
  • 코드와 실행 오류 확인
  • 브라우저 콘솔 정보 확인

변경 기록 활용

  • 히스토리 조회와 상태 비교
  • 이전 상태 확인
  • 선택한 상태 복원
Natural Language

도구 이름을 외우지 않아도 됩니다

평소 AI와 대화하듯 원하는 작업을 설명하면 AI 클라이언트가 필요한 PageRivet MCP 도구를 선택해 프로젝트를 확인하고 작업합니다.

“메인 페이지 상단에 다운로드 버튼을 추가하고 전체 디자인에 어울리게 만들어줘.”
“모바일 화면에서 메뉴가 깨지는 원인을 찾아서 수정해줘.”
“기존 페이지 스타일에 맞춰 새로운 소개 페이지를 만들어줘.”
Safe Changes

AI 변경도 PageRivet의 작업 흐름을 따릅니다

AI는 검증과 히스토리 시스템을 우회하지 않습니다. 사용자는 변경 과정을 확인하고 문제가 생기면 이전 상태로 돌아갈 수 있습니다.

프로젝트 상태 확인→변경 작업→코드 검증→사용자 승인→히스토리 기록
Local Connection

로컬에서 연결되는 협업 구조

PageRivet MCP 서버는 사용자의 PC에서 실행되며 AI 클라이언트와 활성 프로젝트 사이를 연결합니다.

사용자 · 자연어 요청↓AI Client↓ MCPPageRivet MCP Server↓HTML · CSS · JavaScript Project
