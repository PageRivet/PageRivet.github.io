Latest Update 2026.09.02 PageRivet 3.3.0-beta.2 Update and Diagnostics Tool Announcement

Alongside the PageRivet 3.3.0-beta.2 update, we have added PageRivet Diagnostics, a dedicated tool designed to help identify issues more accurately.

PageRivet 3.3.0-beta.2 Update

This release adds a docking system that lets you arrange the workspace, save and restore layouts, create custom themes, browse and search the project source tree, restore History entries, and manage settings in a unified window.

It also supports Jekyll site preview for projects with _config.yml and improves the overall workspace, including Errors/Debug, panels, tabs, and floating windows.

Existing HTML and PageRivet YAML preview, project editing and saving, History, Recovery, resources, export, and MCP features remain available.

PageRivet Diagnostics Added

A separate PageRivet Diagnostics tool is now provided to help investigate problems encountered while using PageRivet.

The tool checks information useful for identifying possible causes, including the PageRivet installation and runtime environment, WebView2, MCP connections, related runtimes, and application status, then generates a diagnostics report.

When contacting us or filing a bug report about a PageRivet issue, please run the diagnostics tool and attach the generated report whenever possible.

Even when the cause is difficult to determine from a symptom description alone, the report can provide useful information about the runtime environment and related status, helping us investigate the issue more accurately.

Optional System Information

The Include system information option is optional.

When enabled, the diagnostics report may include the following system configuration and runtime information for issue analysis:

  • Windows edition, version, build, and system architecture
  • System manufacturer, product name, and BIOS version
  • CPU, GPU, and graphics driver information
  • Physical memory capacity and usage
  • Storage type, file system, and capacity for PageRivet-related drives
  • .NET, WebView2, and Jekyll runtime information
  • System uptime, time zone, and display culture

The diagnostics tool is designed not to collect usernames, computer names, IP addresses, MAC addresses, Wi-Fi SSIDs, proxy addresses, original path text, device, disk, or monitor serial numbers, or Windows product keys.

If you do not want to provide system configuration information, you can run diagnostics without selecting Include system information.

When Reporting an Issue

If you encounter an error or unexpected behavior while using PageRivet, including the following information will help us investigate:

  • A description of the issue and what you were doing when it occurred
  • A screenshot or error message, when available
  • The diagnostics report generated by PageRivet Diagnostics

We will continue improving PageRivet based on issues and feedback found in real-world use.

Thank you.

최신 업데이트 2026.09.02 PageRivet 3.3.0-beta.2 업데이트 및 진단기 추가 안내

PageRivet 3.3.0-beta.2 업데이트와 함께, 사용 중 발생하는 문제를 보다 정확하게 확인하기 위한 PageRivet 전용 진단기(PageRivet Diagnostics)를 추가했습니다.

PageRivet 3.3.0-beta.2 업데이트

이번 버전에서는 사용자가 직접 작업공간을 구성할 수 있는 도킹 시스템과 레이아웃 저장·복원, 사용자 지정 테마, 프로젝트 소스 트리 및 검색, History 복원, 통합 설정창 등이 추가되었습니다.

또한 _config.yml 기반의 Jekyll 사이트 미리보기를 지원하며, 오류/디버그 표시와 패널·탭·독립 창 등 전반적인 작업 환경도 개선했습니다.

기존 HTML 및 PageRivet YAML 미리보기, 프로젝트 편집·저장, History, Recovery, 리소스, 내보내기와 MCP 기능은 그대로 유지됩니다.

PageRivet 전용 진단기 추가

PageRivet을 사용하면서 발생하는 문제를 확인하기 위한 별도의 PageRivet Diagnostics를 함께 제공합니다.

진단기는 PageRivet의 설치 및 실행 환경을 비롯해 WebView2, MCP 연결, 관련 런타임과 프로그램 상태 등 문제의 원인을 파악하는 데 필요한 여러 항목을 확인하고 진단 결과를 보고서로 생성합니다.

PageRivet 사용 중 문제가 발생하여 문의 또는 버그 제보를 남기실 경우, 가능하다면 진단기를 실행한 뒤 생성된 진단 결과를 함께 첨부해 주세요.

단순한 증상 설명만으로 원인을 확인하기 어려운 경우에도 진단 결과를 함께 제공해 주시면 실행 환경과 관련 상태를 확인할 수 있어 문제를 보다 정확하게 파악하는 데 도움이 됩니다.

시스템 정보 포함 옵션 안내

진단기의 시스템 정보 포함은 선택 사항입니다.

해당 옵션을 활성화하면 문제 분석을 위해 다음과 같은 시스템 구성 및 실행 환경 정보가 진단 결과에 포함될 수 있습니다.

  • Windows 제품·버전·빌드 및 시스템 아키텍처
  • 시스템 제조사 및 제품명, BIOS 버전
  • CPU 및 GPU, 그래픽 드라이버 정보
  • 물리 메모리 용량 및 사용 상태
  • PageRivet 관련 저장장치의 유형·파일시스템·용량
  • .NET, WebView2, Jekyll 관련 런타임 정보
  • 시스템 가동 시간, 시간대 및 표시 문화권

반면 진단기는 사용자명, 컴퓨터명, IP 주소, MAC 주소, Wi-Fi SSID, 프록시 주소, 경로 원문, 장치·디스크·모니터 시리얼 번호 및 Windows 제품 키를 수집하지 않도록 구성되어 있습니다.

시스템 구성 정보 제공을 원하지 않는 경우 시스템 정보 포함을 선택하지 않고 진단을 진행할 수 있습니다.

문제 문의 시

PageRivet 사용 중 오류나 예상하지 못한 동작이 발생한다면 다음 내용을 함께 전달해 주시면 문제 확인에 도움이 됩니다.

  • 발생한 문제와 당시 수행했던 작업
  • 가능하다면 문제가 발생한 화면 또는 오류 메시지
  • PageRivet Diagnostics에서 생성한 진단 결과

실제 사용 환경에서 확인되는 문제와 피드백을 바탕으로 PageRivet을 지속적으로 개선하겠습니다.

Latest Notice 2026.08.28 PageRivet UI Improvements and Update Schedule

PageRivet is currently being improved to provide a more flexible and convenient working environment.

Instead of relying only on a fixed interface layout, we are working toward allowing users to arrange and adjust the workspace layout to better match their own workflow.

A More Flexible Workspace

Different users may focus on different panels and follow different workflows while working in PageRivet.

To better support these differences, we are improving the current fixed layout so that users can organize the workspace more flexibly according to their needs.

This work is intended to improve usability rather than simply change the appearance of the application.

Layout-related features will be introduced and verified gradually while preserving the stability and major functionality of PageRivet.

Update Schedule Changes

Since the initial public release, PageRivet has received frequent updates as new features, improvements, and stabilization work have progressed rapidly.

While this has made it possible to address issues and improve the application quickly, we recognize that frequent version changes can also make it inconvenient for users to repeatedly check for and replace releases.

For this reason, starting with version 3.3.0-beta.2, regular updates will generally be released on Wednesday or Thursday each week, except when an urgent patch is required.

Whenever possible, improvements and fixes identified during the week will be grouped into a scheduled release instead of being distributed through unnecessarily frequent version changes.

Urgent Patches

An update may still be released outside the regular schedule if an issue requires immediate attention, including:

  • Errors that significantly affect normal use of the application
  • Issues that may risk project or user data
  • Security-related problems
  • Serious defects that prevent major features from functioning normally

Non-urgent improvements and general bug fixes will, whenever possible, be included in the regular update schedule.

User Feedback

PageRivet continues to improve based on issues and feedback discovered through real-world use.

If you encounter any inconvenience, find something that could be improved, or have a suggestion for a useful feature, please feel free to share your feedback.

We will continue working to make PageRivet more stable, flexible, and convenient to use.

Thank you for your continued interest and feedback.

Latest Notice 2026.08.27 Avalonia Migration Completed and 3.3.0-beta.1 Announcement

The Avalonia migration of PageRivet and the replacement of the previous UI architecture have now been completed.

Starting with version 3.3.0-beta.1, you can use the new Avalonia-based version of PageRivet.

Avalonia Migration Completed

The previous Windows-specific UI architecture has been replaced with Avalonia, and the major features have been confirmed to work correctly in the current development environment.

Verification has also been carried out to ensure that the major features of the existing PageRivet continue to work properly under the new architecture, including project editing, preview, MCP integration, and related workflows.

Why This Release Is Labeled Beta

PageRivet is working normally in the current development environment, but actual user environments may differ depending on factors such as the Windows version, hardware configuration, WebView environment, file permissions, security software, and other system settings.

Because of these differences, unexpected issues—both minor and significant—may still occur during real-world use.

For this reason, the first public release following the Avalonia migration is being distributed with a beta tag. Starting with 3.3.0-beta.1, we will use feedback and issues found in actual user environments to further improve stability.

The beta label does not mean that PageRivet is unusable. It means that the new Avalonia-based architecture still requires additional verification across a wider range of real-world environments.

macOS and Linux Support

As mentioned previously, we currently do not have suitable development and testing environments for macOS or Linux.

The Avalonia migration leaves the technical path open for future expansion to both operating systems, but because we cannot currently perform sufficient testing in real environments, we are not able to officially promise macOS or Linux support at this time.

Version 3.3.0-beta.1 is currently developed and verified primarily for Windows.

If suitable macOS or Linux testing environments become available in the future and proper verification becomes possible, we will consider expanding PageRivet support to those operating systems as well.

Next Steps

For the time being, development will focus on the following areas:

  • Real-world user environment testing for 3.3.0-beta.1
  • Identifying regressions introduced during the Avalonia migration
  • Improving UI and feature stability
  • Revalidating MCP and project workflows
  • Fixing issues based on user feedback
  • Reviewing the transition from beta to a stable release after sufficient stabilization

If issues are discovered during actual use or if there are important changes, we will continue to share updates through the official PageRivet website and related platforms.

Thank you.

최신 안내 2026.08.27 Avalonia 이식 완료 및 3.3.0-beta.1 안내

이제 3.3.0-beta.1 버전부터 Avalonia 기반으로 전환된 새로운 PageRivet을 사용할 수 있습니다.

Avalonia 전환 완료

기존 Windows 전용 UI 구조를 Avalonia 기반으로 교체하는 작업을 마쳤으며, 현재 제작 및 개발 환경에서는 주요 기능이 정상적으로 동작하는 것을 확인했습니다.

기존 PageRivet의 주요 기능을 유지하면서 새로운 구조에서도 프로젝트 편집, 미리보기, MCP 연동 및 관련 기능들이 정상적으로 동작하도록 검증을 진행했습니다.

Beta 버전으로 제공하는 이유

현재 제작 환경에서는 정상적인 동작을 확인했지만, 실제 사용자 환경은 운영체제 버전, 하드웨어 구성, WebView 환경, 파일 권한, 보안 프로그램 및 기타 시스템 설정 등에 따라 차이가 있을 수 있습니다.

따라서 실제 사용 과정에서 예상하지 못한 크고 작은 문제가 발생할 가능성이 있습니다.

이러한 이유로 Avalonia 전환 이후 첫 공개 버전에는 beta 태그를 적용했으며, 3.3.0-beta.1부터 실제 사용자 환경에서 발생하는 문제와 피드백을 확인하며 안정성을 보완할 예정입니다.

beta 표시는 PageRivet을 사용할 수 없는 상태라는 의미가 아니라, 새로운 Avalonia 구조가 다양한 실제 환경에서도 안정적으로 동작하는지 추가 검증이 필요한 단계라는 의미입니다.

macOS 및 Linux 지원

앞서 안내드린 것과 마찬가지로 현재 macOS와 Linux에 대한 실제 개발 및 테스트 환경은 마련되어 있지 않습니다.

Avalonia 전환을 통해 두 운영체제로 확장할 수 있는 구조와 가능성은 열어두었지만, 실제 환경에서 충분한 테스트를 수행할 수 없는 상태이므로 현재 시점에서 macOS 및 Linux의 공식 지원을 약속드리기는 어렵습니다.

현재 3.3.0-beta.1은 Windows 환경을 기준으로 개발 및 검증하고 있습니다.

향후 macOS 또는 Linux 테스트 환경이 마련되고 충분한 검증이 가능해진다면 해당 운영체제에서도 PageRivet을 사용할 수 있도록 지원 범위를 확대하는 방향으로 검토하겠습니다.

향후 진행

당분간은 다음 작업에 집중할 예정입니다.

  • 3.3.0-beta.1 실제 사용자 환경 테스트
  • Avalonia 전환 이후 발생하는 회귀 문제 확인
  • UI 및 기능 안정성 보완
  • MCP 및 프로젝트 작업 흐름 재검증
  • 사용자 피드백을 기반으로 한 문제 수정
  • 안정화 이후 정식 버전 전환 검토

실제 사용 중 문제가 발견되거나 중요한 변경 사항이 있을 경우 공식 홈페이지와 관련 플랫폼을 통해 계속 안내드리겠습니다.

Latest Notice 2026.08.27 Avalonia Migration Progress Update

The Avalonia migration of PageRivet has now entered its final stages.

Most of the major functionality has been migrated, and the current focus is on reviewing the overall structure, reducing unnecessary coupling and duplication, and making sure the existing features continue to work reliably under the new architecture.

Windows Support

Development and testing are currently being carried out primarily on Windows.

A significant portion of the major functionality has already been migrated successfully, and based on the current progress, we believe it is reasonable to expect the Avalonia-based Windows version of PageRivet to be completed.

However, final verification and structural cleanup are still in progress. If unexpected issues or additional work are discovered during development, the completion date may be delayed beyond the current expectation.

Rather than setting a fixed release date in advance, we plan to complete the migration only after confirming that the major existing features and overall stability of PageRivet have been sufficiently preserved.

macOS and Linux Support

Unfortunately, we currently do not have suitable testing environments for macOS or Linux.

One of the reasons for migrating to Avalonia is to move away from a strictly Windows-specific UI architecture and leave a path open for future support of additional operating systems.

This means that macOS and Linux support has not been ruled out.

However, we do not believe it would be appropriate to officially promise support for operating systems that we are currently unable to test properly on real environments.

For the time being, Windows support will remain the primary focus. macOS and Linux compatibility will be considered for future expansion if suitable testing environments become available and proper verification becomes possible.

We cannot guarantee when or whether such testing environments will become available. However, if the necessary conditions are eventually met, we will do our best to expand PageRivet so that it can also be used on macOS and Linux.

Next Steps

For now, development will focus on the following areas:

  • Final cleanup of the Avalonia migration architecture
  • Reverification of major existing PageRivet features
  • Stability testing on Windows

최신 안내 2026.08.27 Avalonia 이식 진행 상황 안내

PageRivet의 Avalonia 이식 작업이 현재 마무리 단계에 들어갔습니다.

주요 기능의 이식은 상당 부분 완료되었으며, 현재는 전체적인 구조를 다시 점검하고 중복되거나 불필요하게 결합된 부분을 정리하면서 기존 기능이 새로운 구조에서도 안정적으로 동작하도록 개선하는 작업을 진행하고 있습니다.

Windows 지원

현재 개발 및 테스트는 Windows 환경을 기준으로 진행하고 있습니다.

Windows 환경에서는 주요 기능의 이식이 상당 부분 완료되었으며, 현재 상태라면 Avalonia 기반 PageRivet의 Windows 이식 완료를 기대해도 괜찮을 것으로 보고 있습니다.

다만 아직 최종 검증과 구조 정리 작업이 남아 있으며, 개발 과정에서 예상하지 못한 문제나 추가 수정이 필요한 부분이 발견될 경우 이식 완료 시점은 현재 예상보다 늦어질 수 있습니다.

정확한 완료 날짜를 미리 확정하기보다는, 기존 PageRivet의 주요 기능과 안정성이 충분히 유지되는 것을 확인한 뒤 다음 단계로 진행할 예정입니다.

macOS 및 Linux 지원

아쉬운 점은 현재 macOS와 Linux에 대한 실제 테스트 환경이 마련되어 있지 않다는 것입니다.

Avalonia로 이식하면서 기존 Windows 전용 구조에서 벗어나 다른 운영체제로 확장할 수 있는 기반과 통로는 열어두고 있습니다. 따라서 macOS와 Linux 지원을 기술적으로 배제한 것은 아닙니다.

다만 실제 환경에서 충분한 테스트를 진행하지 않은 상태에서 공식적인 지원을 약속하는 것은 적절하지 않다고 판단하고 있습니다.

현재로서는 Windows 지원을 우선하며, macOS와 Linux는 향후 테스트 환경이 마련되고 실제 검증이 가능해질 경우 지원 범위를 확장하는 방향으로 검토할 예정입니다.

언제 해당 환경을 마련할 수 있을지는 현재로서는 장담하기 어렵습니다. 하지만 여건이 갖춰진다면 macOS와 Linux에서도 PageRivet을 사용할 수 있도록 가능한 범위에서 최선을 다해 지원을 확대하겠습니다.
